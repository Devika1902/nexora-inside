# Sample data guide

All records are deterministic fictional examples generated by `tools/generate_sample_data.py`. Each dataset is available as UTF-8 CSV and JSON. The CSV files open in Excel or LibreOffice Calc; the JSON files suit import exercises and prototypes.

| Dataset | Records | Main use |
| --- | ---: | --- |
| announcements | 650 | Content calendar, audiences, channel, owners, approvers, review and publication dates |
| events | 650 | Event portfolio, dates, capacity, registrations, budget and status |
| tasks | 650 | Work allocation, priorities, deadlines, status and dependencies |
| people | 650 | Fictional directory and audience planning |
| suppliers | 600 | Supplier category, quote, confirmation, insurance and access notes |
| registrations | 650 | RSVP, event attendance, dietary and access-request workflow examples |

## Important fields

- Dates use ISO `YYYY-MM-DD` format so they sort correctly.
- EUR amounts are numeric values in the Excel tracker and plain numbers in CSV/JSON.
- IDs link records where a shared event or employee is referenced. The Annual Employee Celebration uses event ID `EVT-NX-2026-01`.
- Email addresses use `.example`, a reserved example domain. They do not represent real contacts.
- Registration needs are fictional and should still be treated as potentially sensitive when demonstrating a workflow. In a real system, restrict access to the people who need the information.
- The event attendance sample records 192 registrations, 174 attendees and 18 no-shows for the fictional celebration to match the illustrative post-event report.
