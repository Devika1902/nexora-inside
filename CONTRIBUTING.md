# Reuse and contribution guide

This portfolio is designed to be adapted. Keep the original fictional sample clearly labelled, then replace it with approved content if using the material for a different scenario.

## Before adapting the materials

- Confirm company names, brand assets, policies, budget authority, event details and approval roles with the appropriate owners.
- Use consented employee stories and photographs only.
- Replace the fictional careers address and update the Word QR field before distributing recruitment material.
- Do not put real employee, candidate, supplier or contact information into a public repository.
- Verify accessibility, privacy, retention and records requirements with the organization.

## Suggested Git workflow

1. Create a branch for a focused change.
2. Update the source document and, if relevant, its tracker or dataset field guide.
3. Keep synthetic-data assumptions documented.
4. Review the rendered document or slide before merging.
5. Do not add generated temporary previews from `.build/`.
